# Inspirations fournies par l’utilisateur

Les deux HTML sont uniquement des idées de couleurs, animations et défilement. Ils ne sont ni des spécifications impératives ni des sources de statistiques. Les chiffres, marques et avis fictifs ne doivent pas être repris.

- Ochre : ocre, sauge, bleu profond, matière grainée, respiration lente, transitions fluides.
- Wayfind : grandes cartes superposées, légère rotation/profondeur au défilement et séquence horizontale. Adapter librement à une app iPhone.

Les fichiers sont archivés comme références ; ne pas charger leurs scripts dans ONDE.
