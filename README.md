# ONDE, Le Donjon et EN•VIE/CORPS

[Ouvrir l’accueil commun](https://cgiy.github.io/onde-a-deux/) : choisir ONDE, [Le Donjon](https://cgiy.github.io/mes_apps/) ou [EN•VIE/CORPS](https://cgiy.github.io/onde-a-deux/en-vie-corps/).

- **ONDE** aide le duo à choisir ses envies, séparément puis ensemble.
- **Le Donjon** transforme la soirée en aventure partagée.
- **EN•VIE/CORPS** documente les bénéfices, limites et conseils autour d’une expérience, puis permet de noter « On l’a refait ! » dans une jauge hebdomadaire.

Les applications sont conçues d’abord pour le téléphone et hébergées sur GitHub Pages. La synchronisation passe par Supabase avec un code privé et un jeton propre à chaque appareil. EN•VIE/CORPS ne synchronise aucun texte intime libre : uniquement les identifiants des fiches, la liste « à refaire » et la progression de la semaine.

Les schémas de tables figurent dans `supabase/`. Une personne qui possède le code d’un espace peut tenter de le rejoindre : ne partagez pas ce code publiquement.
