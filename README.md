# ONDE et Le Donjon

[Ouvrir l’accueil commun](https://cgiy.github.io/onde-a-deux/) : choisir ONDE ou [Le Donjon](https://cgiy.github.io/mes_apps/).

Chaque jeu se joue sur deux téléphones avec A et C. ONDE conserve ses choix séparés jusqu’au résultat commun. Le Donjon utilise une seule partie partagée : chaque téléphone joue son propre héros, dans les mêmes salles et combats.

Les pages sont hébergées sur GitHub Pages ; la synchronisation et les sessions de 24 h passent par Supabase. Les schémas de tables figurent dans `supabase/`. Une personne qui possède le code d’une partie peut tenter de la rejoindre : ne partagez pas ce code publiquement.
